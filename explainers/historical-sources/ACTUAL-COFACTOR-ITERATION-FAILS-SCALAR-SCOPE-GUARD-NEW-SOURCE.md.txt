# The actual scalar cofactor identity cannot be iterated automatically

**Status:** new exact scope guard by `/root`, 2026-09-23; pending
independent audit. This is a scalar example, not a ternary source.
It leaves the general conjecture open.

The accepted cofactor-row degree theorem does not assert that the
actual cofactor matrix itself satisfies the scalar identity. That
stronger assertion is false, even for a bipartite source with
nonzero hafnian at both iterations.

Let w be a primitive cube root of unity and put

    N = [[-1, 1,  1,  1,  1 ],
         [ 1, w,  w², 0,  0 ],
         [ 1, w², w,  0,  0 ],
         [ 1, 0,  0,  w,  w²],
         [ 1, 0,  0,  w², w ]].

This N also arises by the accepted scalar parallel gluing of two
three-by-three Fourier cross blocks along their first cross pair.
For a square matrix X let P(X)[i,j]=per(X with row i and column j
deleted). Direct expansion using 1+w+w²=0 gives per(N)=3 and

    K=P(N)=[[1, 1,  1,  1,  1 ],
            [1, w², w,  1,  1 ],
            [1, w,  w², 1,  1 ],
            [1, 1,  1,  w², w ],
            [1, 1,  1,  w,  w²]].

Multiplication gives NK^T=3I. Now per(K)=21, while

    P(K)=[[9, 3,  3,   3,   3  ],
          [3, 3w, 3w², 6,   6  ],
          [3, 3w²,3w,  6,   6  ],
          [3, 6,  6,   3w,  3w²],
          [3, 6,  6,   3w², 3w ]],

and the residual is nonzero:

    KP(K)^T-21I = [[ 0,12,12,12,12],
                   [12, 0,12,-6,-6],
                   [12,12, 0,-6,-6],
                   [12,-6,-6, 0,12],
                   [12,-6,-6,12, 0]].

For the ten-by-ten symmetric zero-diagonal matrix

    M=[[0,N],[N^T,0]],

the ACTUAL hafnian cofactor matrix is C_M=[[0,K],[K^T,0]]: equal-shore
deletions have no matching, and opposite-shore deletions give exactly
the displayed permanental cofactors. Therefore

    haf(M)=3,       M C_M=3I,
    haf(C_M)=21,    C_M C_(C_M) != 21I.

The companion `verify_cofactor_iteration_guard.py` checks these
identities independently by recursive ACTUAL hafnian matching sums
on all ten sites in exact integer-pair arithmetic for Z[w]. It does
not define cofactors from an inverse or use floating-point residuals.
A separate SymPy permanent calculation agrees with both displayed
cofactor matrices and the residual.

Consequently scalar graph restrictions cannot be transferred to
the support of C_M by asserting scalar-class closure. Cofactor-row
restrictions proved directly from the ORIGINAL identity remain valid.
Extra full ternary hypotheses could still support a separate theorem;
this example neither proves nor disproves such a theorem.
