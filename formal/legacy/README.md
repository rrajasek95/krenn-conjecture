These files preserve the earlier clean-pair descent program and its original
Lean 4.27.0 environment. Statements about unfinished work describe that
historical project. The [completed all-orders formalization](../README.md)
has its own toolchain and verification instructions.

- [FORMALIZATION.md](FORMALIZATION.md): the original dependency ledger.
- [MonochromaticQuantumGraphKeyLemmas.lean](MonochromaticQuantumGraphKeyLemmas.lean): the phase-one proved lemmas.
- [CLAUDE_PHASE1.md](CLAUDE_PHASE1.md): the original task and environment notes.

Their contents are preserved verbatim, including historical paths and commands.
Compatibility symlinks for the ledger and Lean source remain in `formal/`.
