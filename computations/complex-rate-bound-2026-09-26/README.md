# Complex six-site rate: a local bound and an unavailable shortcut

[Read the theorem, proof, and diagram](../../notes/complex-rate-bound-2026-09-26.md).
**New research; not independently audited or certified.**

This package supports two conclusions:

1. Every arbitrary complex source within coefficient distance `1/1000` of
   the prism's two-triangle limit obeys `||E|| >= |lambda|^3 / 2`. This gives
   an explicit square-root rate bound throughout that neighborhood, including
   off-color entries and unequal pure amplitudes. The exponent is sharp there.
2. Even with pure-amplitude balance equations, `lambda^3` is not in the ideal
   generated by the error coefficients. This rules out that polynomial
   certificate globally. It does **not** rule out a global square-root inequality.

A useful rate bound for every complex source is still open. The local theorem
does not classify the other zero-output limits.

## Replay

From the project root, with Python 3.10+ and no additional dependencies:

```sh
python3 computations/complex-rate-bound-2026-09-26/verify.py
python3 -O computations/complex-rate-bound-2026-09-26/verify.py
python3 -I -S computations/complex-rate-bound-2026-09-26/verify.py
```

The checker takes less than a second in the development environment. It checks:

| Finite claim | Exact check |
|---|---|
| `H = U B V^T + K(B)` | All 729 output coefficients and all 15 matchings |
| Full first-order freedom | 81 independent crossing columns, 54 internal kernel entries |
| Second-order restrictions | 48 separate equations; six original internal entries survive |
| Unavoidable cubic term | Coefficient of `bcabca` equals 1 |
| Local estimate | Every rational rounding and the strict contradiction margin |
| Balanced cubic nonmembership | Integer functional annihilates all 18,420 relevant generator multiples |
| Nonzero target | Functional evaluates to 64 on the product of the three pure amplitudes |
| Corruption control | A changed functional entry is rejected |

[verification.json](verification.json) records the results and SHA-256 hashes
of the checker, generator, certificate, proof note, and preceding feasibility
note. The finite checks do not replace independent review of the written
norm argument or the completeness of the ideal-sector reduction.

## Certificate generation

```sh
python3 computations/complex-rate-bound-2026-09-26/build_dual.py
```

This prints [balanced-dual.json](balanced-dual.json) deterministically. It takes
about ten seconds locally. A modular linear calculation finds a candidate;
the generator then lifts it to rational coefficients and verifies all column
identities exactly before emitting an integer functional. No finite-field
nonmembership inference is used.

The verifier uses a different multigraph enumeration and constructs each
mixed output polynomial directly from the 15 physical perfect matchings.
It does not import or trust the generator's elimination routine.

## Relationship to earlier work

This extends the [feasibility gate](../universal-rate-gate-2026-09-26/README.md),
which treated nonnegative sources and a fixed prism tangent. The new local
theorem allows every complex perturbation in a full neighborhood. The new
negative certificate also includes balance equations, which the earlier
32-term functional did not address. The certified no-go packages are unchanged.
