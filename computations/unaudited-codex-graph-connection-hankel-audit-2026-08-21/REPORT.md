# Graph connection matrices / Hankel audit

## Outcome

Finite connection rank does force the familiar three-state **observable
quotient** of the GHZ table.  It cannot force an untrimmed three-state Krenn
source.  The quotient by the connection-pairing radical is built into graph
algebra theory, and both abstract and literal source-faithful controls show
that the radical can contain source data relevant below the top matching
sector.

The exact dichotomy is:

1. use only the fixed `K8` top tensor fixed by the GHZ equations, and invisible
   source directions are erased; or
2. use every labelled gluing/completion, which detects those directions but
   asks for connection entries not determined by the GHZ equation.

No finite-rank theorem bridges this gap.  A viable replacement must retain
lower matching sectors and separately prove that their radical is cap-benign.

## 1. Classical interface and its exact mismatch

For a scalar graph parameter `f` defined on all finite graphs, the `k`-th
connection matrix is

```text
M_k(F,G) = f(F glued along the k labels to G).
```

Its graph algebra has pairing `<x,y>=f(xy)`, and

```text
rank M_k = dim(GraphAlgebra_k / Rad <,>).
```

This quotient is explicit in Lovász's factorization `M=N^T A N`; twin
reduction and the nullspace quotient are essential parts of the theory.
The homomorphism-function characterization additionally assumes a scalar
multiplicative graph parameter on every graph, reflection positivity, and
exponential rank bounds.  The Krenn data instead consist of arbitrary complex,
site-pair-dependent blocks on one fixed labelled `K8`, and the conjectural
equation fixes only its top one-hot tensor.

Primary references:

- Freedman--Lovász--Schrijver,
  [Reflection positivity, rank connectivity, and homomorphism of graphs](https://arxiv.org/abs/math/0404468).
- Lovász,
  [The rank of connection matrices and the dimension of graph algebras](https://arxiv.org/abs/math/0408232).
- Szegedy,
  [Edge coloring models and reflection positivity](https://arxiv.org/abs/math/0505035).

## 2. Exact untrimmed no-go

Take the three-state copy algebra with idempotents `e0,e1,e2`, and adjoin a
square-zero state `n`:

```text
ei*ej = delta_ij ei,
e0*n = n,
e1*n = e2*n = n^2 = 0,
lambda(ei)=1,
lambda(n)=0.
```

The algebra is associative and unital.  Its connection pairing is

```text
diag(1,1,1,0),
```

so it has rank three although the untrimmed algebra has dimension four.  The
ideal spanned by `n` is invisible to every connection value and the quotient
is exactly the three-state copy algebra.  Arbitrarily large invisible ideals
may be added in the same way.

Thus a rank-three GHZ table cannot determine the untrimmed source without an
independent nondegeneracy/injectivity theorem.

## 3. Literal controls

### `n=4`

The integral one-factorization source realizes ternary GHZ exactly.  Across
each `2+2` cut, one pure colour uses zero crossing edges while the other two
use two crossing edges.  Nevertheless every nontrivial GHZ flattening has
rank three.  The minimal quotient therefore identifies a common three-state
output while forgetting distinct source boundary-connectivity types.

### Invisible `K8` chord

Start with the perfect matching

```text
01|23|45|67
```

and add chord `02`.  The complete eight-site matching output is unchanged,
and the top cofactor of `02` is zero.  But the lower divided-power supports
change by respectively `1,2,1,0` matchings in degrees `1,2,3,4`; in
particular `02|45|67` is a new degree-three term.

A full labelled connection oracle detects the chord by gluing completion
`13|45|67`, which creates the new top matching `02|13|45|67`.  Those
completion values, however, are not constrained by equality of the original
fixed-`K8` tensor.  This is the exact top-only/full-connection dichotomy.

### Laurent boundary

The frozen twelve-cell family has

```text
H(A(t)) = GHZ + t(e_12012000+e_21000012).
```

At finite nonzero `t`, its `2+6`, `3+5`, and `4+4` flattenings have ranks four
or five on all but one exceptional two-site cut.  At the base-locus limit all
254 nontrivial GHZ flattenings have rank three.  The checker also replays seven
distinct output-invisible valuation redistributions.  Hence top connection
rank is a closed border datum and cannot distinguish exact finite-source
membership from the exceptional GHZ direction.

## 4. Terminal verdict and surviving target

Connection/Hankel theory proves no source quotient before radical trimming.
The strongest source-faithful replacement is to retain

```text
(q, q^[2], q^[3], q^[4])
```

in a relative labelled connection packet and prove, on the exact X5 fibre,
that its pairing radical is generated by inactive/isolated directions or that
any nonzero radical direction yields an active clean cap.  This would be a
genuinely nonlinear source theorem: lower sectors are not determined by GHZ,
and the frozen literal site-down hierarchy only rebrackets the existing 6,558
mixed top rows.
