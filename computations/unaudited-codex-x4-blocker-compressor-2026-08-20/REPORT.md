## 1. Atomic response data

pair `p,q`, let `U` be its six-site complement, and let

```text

```

For each residual edge `a<b`, define the atomic map

```text

rho_ab^(alpha,beta)(K)

     A_pa[i,alpha] A_qb[j,beta]

```

Thus only 15 atomic maps are needed for a fixed pair.  For a star at `v`,
let `F_C` be the ten residual edges not incident with `v`.  For a triangle

case put

```text
W_C = sum_{ab in F_C} rowspan(rho_ab)  subset C*.        (2)
```

The previous 90-by-9 and 108-by-9 matrices are just vertically stacked
presentations of (2).  They are not independent objects.  The checker

## 2. One quartic condition replaces four blocker branches

Define the four activity functionals

```text

q_pq(K)    = kappa_0 kappa_1 kappa_2 s_pq.              (3)
```

Let `V_C=ker(L_C)=ann(W_C)`.  A carrier is active exactly when some
`K in V_C` has `q_pq(K) != 0`.  Therefore it fails exactly when the
restriction of `q_pq` to `V_C` is the zero polynomial.  The vanishing ideal
of the linear space `V_C` is generated by `W_C`, so this is equivalent to

```text

```

The use of an infinite field is exactly what identifies absence of an active
point with polynomial vanishing; no finite-field version is claimed.  This
also proves directly that (4) is equivalent to the old disjunction.
Indeed, in the domain `Sym(V_C*)`, the product


is zero if and only if one factor is zero.  A factor is zero precisely when
that activity functional belongs to `W_C`.  The argument includes
`V_C=0`, inactive pairs, and every rank of `L_C`.

This removes the apparent `4^728` blocker-assignment expansion.  It does not
