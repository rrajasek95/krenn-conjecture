instructions, and review status. This directory preserves earlier research

- [Previous README](README-before-cleanup-2026-09-26.md): the working overview
  immediately before the repository cleanup, including its older status updates.
- [Historical proof sketch](PROOF-SKETCH.md): the accumulated research ledger,

- [Phase-one formalization](../../formal/legacy/README.md): the earlier Lean
  project and its planning documents.
- [Certification ledger](../../certification/SUPERSESSIONS.md): the original

The two snapshots above retain their original repository-relative paths and
wording. The root `PROOF-SKETCH.md` compatibility symlink preserves file access
for older research checkers. Published proof and certification paths remain
unchanged.
