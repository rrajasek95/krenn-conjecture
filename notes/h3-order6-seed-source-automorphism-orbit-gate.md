# The first seed orbit leaves a rank-77 fixed-grade response complement

## Outcome

The two exact first-face seed types do not generate the full rank-`153`
site-repeating response envelope under the committed source symmetries when
all word, fine, direct-free and repeated-pair labels are retained.

Let `V_seed` be the rank-`76` constrained image of all `819` order-six
operators containing

\[
                    (01{:}11)\wedge(07{:}11).         \tag{1}
\]

Close it under the group generated by

```text
s       = residual-site swap (0 1),
theta   = endpoint transpose (0 1)(6 7),
w_tail  = simultaneous colour Weyl at sites 2 and 5.
```

This group has order eight.  In the fixed labelled rank-`153` image, only
the identity transports every seed vector back into the same component.
Every nonidentity element exports some coordinate to a conjugate word/fine
or direct-free component.  Consequently

\[
       \operatorname {rank} V_{\rm seed}^{\rm internal}=76,
       \qquad \dim(V_{\rm full}/V_{\rm seed}^{\rm internal})=77.       \tag{2}
\]

Both primes `1,000,003` and `999,983` give the same result.

Checker:
[`verify_h3_order6_seed_source_automorphism_orbit_gate.py`](../computations/verify_h3_order6_seed_source_automorphism_orbit_gate.py).

## Literal orbit audit

Each transported seed space still has rank `76` on `84` coordinates, but
the support escaping the fixed `159` rows is:

| transformation | coordinates outside the fixed component |
|---|---:|
| `s` | 17 |
| `theta` | 25 |
| `(6 7)` | 26 |
| `w_tail` | 38 |
| `s*w_tail` | 55 |
| `theta*w_tail` | 58 |
| `(6 7)*w_tail` | 61 |

Thus none is a fixed-grade endomorphism of the pinned rank-`153` block.
Across all conjugate components, before any grade identification, the eight
transported spaces have rank `200`.  That number cannot be used as a rank
inside the fixed envelope: it includes rows whose literal labels are absent
there.

This matches the earlier endpoint-transpose warning.  A physical symmetry
may transport the complete source to a conjugate repeated component without
providing the shifted comparison which identifies that component with the
canonical faces-`(3,5)` grade.

## Minimal fixed-grade linear generator certificate

The checker builds a canonical complement rather than reporting only (2).
It inserts the rank-`76` seed basis first, then scans the full source-derived
constrained basis in lexicographic pivot order.  Exactly `77` further monic
vectors are necessary and sufficient:

```text
seed-containing constrained basis             76
canonical quotient complement                  77
full fixed-grade response envelope            153.
```

The two primes produce the same ordered pivot-row digest.  The checker
freezes the first ten literal pivot rows and a histogram by

```text
number of shared sites,
number of direct-free cells,
same uncoloured edge,
same decorated cell.
```

Therefore a minimal *linear* fixed-grade presentation consists of the 76
seed generators plus 77 complement generators.  Equivalently, a new natural
constructor may replace the latter list only if its internal orbit has rank
77 in this exact quotient.

The certificate does not say that 77 unrelated physical atom *types* are
necessary.  One shifted grade-identification or Taylor-family constructor
could generate many of them.  It says precisely what rank such a constructor
must supply.

## Consequence for the cap landing

All these vectors remain inside the response mixed-jet envelope.  Even a
hypothetical symmetry that filled the rank-77 quotient would not create the
operation-changing matrix unit

\[
                        e_C A e_R.                    \tag{3}
\]

The cap landing remains a separate EqSystem-to-`AugP2` bimodule datum.  The
current result only makes its required response domain finite and explicit.

The next constructive test is whether the 77 complement pivots are precisely
relative Taylor/lcm two-parent cells.  If so, the seed and complement may
admit one common occurrence-resolution augmentation before the independent
operation-changing cap map is imposed.
