# Arbitrary pure-zero unary completion still forces both crossed rows

Date: 2026-08-11

Checker:
`computations/verify_n8_one_bad_endpoint_minor_arbitrary_pure_unary_completion.py`

## Theorem

Keep the four coloured common-`q` cells of the `fb8d482` response packet,
but now allow an arbitrary `00` cell `z_ij` on every edge of the residual
`K6`.  Keep the pinned endpoint-star support.  Then the exact unary equation
`q^[3]=X0`, together with the absence of every mixed unary word, forces both
crossed response rows to have nonzero coefficients.  Consequently no
pure-zero common-`q` completion—of any support size—extends the packet to a
full one-bad source.

This is an ideal calculation, not a support census.

## Eight mixed unary rows

Let `A,B` be the old `11` weights on `24,35`, and `C,D` the old `22`
weights on `05,14`.  The two diagonal response anchors make all four units.
After dividing by those units, four mixed top rows give

```text
z01 = z02 = z13 = z23 = 0.
```

The other four give

```text
g24 = z01*z35 + z03*z15 + z05*z13 = 0,
g35 = z01*z24 + z02*z14 + z04*z12 = 0,
g05 = z12*z34 + z13*z24 + z14*z23 = 0,
g14 = z02*z35 + z03*z25 + z05*z23 = 0.
```

The checker expands the full fifteen-term hafnian and verifies a literal
polynomial identity expressing

```text
haf(z) - z03*z12*z45
```

in the ideal generated by these eight rows.  Thus the unary anchor gives

```text
z03*z12*z45 = 1.
```

There is no radical inference here.  The displayed product is a unit in the
localized coefficient ring, so `z03,z12,z45` are individually units.  The
quadratic mixed rows then force

```text
z15=z25=z04=z34=0.
```

## The two unavoidable crossed coefficients

The pure-zero cofactor after deleting response sites `0,3` is

```text
C03 = z12*z45 + z14*z25 + z15*z24 = z12*z45,
```

and after deleting `1,2` it is

```text
C12 = z03*z45 + z04*z35 + z05*z34 = z03*z45.
```

Both are units.  With the pinned star anchors these are exactly the common
cofactors of the crossed output words

```text
12 @ 100200,       21 @ 012000.
```

Their star factors are units by the two diagonal response equations.  Hence
neither crossed row can vanish.  This closes arbitrary pure-zero additions
without needing an alternating-`C4` argument.

## Scope

All fifteen `00` q cells and their coefficients are arbitrary.  The old
four coloured q cells and endpoint-star support remain pinned.  A completion
using new mixed-colour q cells could add cancellation terms to the eight
mixed unary equations and is not covered.  That is the exact next structural
gate; this theorem does not motivate a raw support search for it.
