## Finite quotient theorem

Let `Q` be the cokernel of the complete augmented physical source map after
passing to the augmentation-private occurrence quotient.  Let `q` be the
marked silent E14 occurrence class and suppose the old unary return acts as

\[
                              T=I_Q.                  \tag{1}
\]

The minimal rank-one operation killing `q` is

\[
                       T'=I_Q-q\otimes h,\qquad h(q)=1. \tag{2}
\]

This form is necessary: if `(I+u tensor phi)q=0`, then `phi(q)` is nonzero
and `u=-q/phi(q)`.  It is sufficient by inspection.  Moreover

\[
 (T')^2=T',\qquad \ker T'=\mathbf Qq,qquad
 \operatorname {im}T'=\ker h.                        \tag{3}
\]

Thus one rank-one update makes the return nilpotent exactly when `Q` is the
one-dimensional cyclic line generated by `q`.  In higher dimension it kills
the marked line but leaves the identity on `Q/Qq`.

Equivalently, attach one physical source column `b` whose private projection
is `q`.  The new cokernel and return are

\[
 Q'=Q/\mathbf Qq,qquad T'=I_{Q'}.                    \tag{4}
\]

Hence the attachment closes the whole quotient if and only if `Q=Qq`.  If
`Q/Qq` is nonzero, finite duality supplies a nonzero covector killing the old
columns and `b`; after full physical typing this is the residual
separator/terminal arm.

\[

\]

\[
 C^2=90C,qquad C\mathbf1=0,qquad \operatorname {rank}C=89. \tag{6}

\[

\]

The full `C` family is rank 89, not rank one.  The rank-one operation in (2)
is one marked column together with a physically typed marked covector.  This

\[

the complete occurrence row gives rank ninety.  Thus a *natural schema*
`g -> c_g`, instantiated over all tags, removes every augmentation-private
structural direction.  One marked instance removes only one line.

## Why the moving-response proposal is still the pointed cell

Write `R=sum_i u_i` for the fixed-word occurrence row and mark `f=u_0`.

\[

\[

It is not tangent to the fixed response hypersurface.  For example, at

\[

association correspondence, not a derivation of the source algebra.
