# The first literal repair SCC contains an exact factorized cycle

## Outcome

The finite literal graph generated by minimum and cost-two repair packets has
one three-vertex strongly connected component:

\[
 R_0=(101222;00),\quad R_3=(101200;00),\quad
 R_5=(111112;01).                                      \tag{1}
\]

There are eight inclusion-minimal directed cycles: six cost-two returns
(R_3\to R_0) and two returns (R_5\to R_0), paired with the corresponding
minimum forward edge.  Label symmetry does not identify them because the
site stabilizer is trivial and operation/fine tags are retained.

The SCC exclusion program stops at the fifth (R_3\to R_0) packet.  Adjoin

\[
 Z=s_0(0;1),\qquad L=q_{12}^{0,1}.                      \tag{2}
\]

Then the two complete rows factor as

\[
 \boxed{
 R_3=X_3bK,\qquad
 R_0=(X_3q_{45}+Xq_{35})K,\qquad
 K=S_0c+ZL.}                                            \tag{3}
\]

Thus (K=0) is a genuine exact full-row cycle.  At the inherited normalized
point, (Z=-1,L=1) closes both rows with all displayed cells nonzero.  There
is no Laurent unit certificate for this cycle.

The cycle is not a global source solution: exhaustive replay creates sixteen
other row changes, whose first private face is

\[
 \boxed{P_0S_1Lb,qquad(001100;01),\quad
        \mathrm{PS},\quad60\mid73\mid12\mid45.}          \tag{4}
\]

This is the precise new frontier.

## Literal SCC construction

The preceding coarse tail census had 30 cost-two packets.  Test each packet
against the three already constructed complete rows, rather than collapsing
landings by the presence of (q_{45}) or (q_{35}).  Exactly eight return to
(R_0):

\[
\begin{array}{c|c}
\text{source row}&\text{presentation-order packet indices}\\ \hline
R_3&3,15,36,48,60,66\\
R_5&22,53.
\end{array}                                              \tag{5}
\]

Together with the minimum edges

\[
 R_0\xrightarrow{X_3}R_3,\qquad
 R_0\xrightarrow{X_5}R_5,                              \tag{6}
\]

these returns make all three vertices mutually reachable.  Each return plus
its forward edge is an inclusion-minimal two-edge directed cycle, giving the
eight circuit supports.

Once (X) and (X_3) are retained, the six sites carry pairwise distinct source
markers

\[
 (P_0),\ (S_0),\ (P_2),\ (S_1,X_3),\ (X),\ (S_2,Y).    \tag{7}
\]

Hence the label-preserving site stabilizer has order one.  In particular the
eight returns remain eight labelled orbits; DQ and PS packets are never
identified.

## The first exact return packet

Packet 60 is operation-PS.  On (R_3), its path has

\[
 p\text{-site}=3,\quad s\text{-site}=0,\quad
 q\text{-matching}=12\mid45,
\]

so its fine matching is

\[
                         63\mid70\mid12\mid45.          \tag{8}
\]

The repair monomial is (X_3ZLb), and it combines with the old
(X_3S_0cb) term to give the first factorization in (3).  At the landing word
(101222), the same packet creates *two* terms:

\[
 X_3ZLq_{45},\qquad XZLq_{35}.                          \tag{9}
\]

Those are exactly the cross products required for the second factorization
in (3).  Dropping either term would incorrectly turn the cycle back into a
unit square.

At the rational normalization,

\[
 S_0=c=L=1,\qquad Z=-1,
\]

so (K=0).  Also (X_3q_{45}+Xq_{35}=-2+2=0), but that second cancellation is
not needed: the common factor already makes both rows zero for arbitrary
nonzero values satisfying (K=0).

## Exhaustive external faces

Insert (Z=-1,L=1) into the complete source packet and replay all 6561 rows.
Both SCC rows remain zero.  There are sixteen incremental row changes and 44
nonzero full residual rows.  The first increment is (4), with value (+1).

The new face uses the inherited (P_0) endpoint at site 0, inherited
(S_1) at site 3, the new edge (L=q_{12}^{0,1}), and inherited pure edge
(b=q_{45}^{0,0}).  Its word/head/fine data are therefore literal and private;
it is not another coarse (q_{45}/q_{35}) reset.

## Consequence

This is the requested stopping condition: a genuine exact full-row directed
cycle exists in the finite minimum/cost-two SCC.  Scalar filtrations and a
blanket SCC unit-exclusion theorem are both false.  The positive datum is the
common-factor schema (3).

It does not yet close the global proof because (4) and fifteen later external
rows remain.  The shortest continuation is to classify minimum mates of
(001100;01) while retaining the factor relation (K=0).  Any successful next
certificate must be compatible with this exact cycle rather than invert its
common factor.
