# The complete E14 unary return has identity augmentation holonomy

## Result

The zero-, one-, two-, and three-new-cell E14 layers are completely closed,
but their support-dependent units do not admit a common triangular promotion
using the currently pinned unary S-pair reductions.

The obstruction is a concrete cycle invariant.  On the free module of 228
marked private occurrences, every canonical unary-times-`q` S-pair returns
to the same marked occurrence with a factor `A` satisfying `A(0)=1`.
Consequently the return operator `T` obeys

\[
                         T\bmod\mathfrak m=I_{228},      \tag{1}
\]

where `m` is generated by the new internal-cell variables.  We call (1) the
**augmentation holonomy**.

Thus 24 returns are literal identity loops and 204 have the form

\[
                             g+c\,m g,                 \tag{2}
\]

with `m` a nonconstant internal monomial.  There are 156 linear higher

The number 228 indexes marked occurrences.  It is not a claim that the
evaluated physical cokernel has dimension 228.  Physical nontriviality is
provided separately by the canonical first-hit calculation: rank `269`

inherits identity holonomy.

## Why no global monomial order works

For an admissible global monomial order, `1<m` for every nonconstant
monomial and multiplication preserves the inequality.  Hence

\[
                              g < m g.                 \tag{3}
\]

For each of the 204 nonconstant returns, (2) therefore cannot be oriented
with `g` as a leading term.  Reversing (3), as a local order would, produces
the infinite descending chain

\[
                       g>mg>m^2g>m^3g>\cdots,          \tag{4}
\]

so it is not a well-founded triangular potential.  The remaining 24 factors
are `g -> g` and give no strict decrease at all.

This sharpens the earlier response-only obstruction.  The 1,108 literal
`G11` pivots have no private-terminal rule and already contain
endpoint-orientation two-cycles.  Unary rows break those immediate
two-cycles, but their complete first reductions produce (1).  The cycle has
moved up one resolution layer rather than disappeared.

## Rees interpretation

Give every new internal variable positive filtration degree.  The
degree-zero part of every return factor is one, so the induced map on the
degree-zero fibre is `I_228`.  This remains the identity after any change of
occurrence basis.  A strict triangular descent on a finite fibre is
nilpotent and has trace zero; here the trace is 228.

Therefore the unaugmented positive-cell Rees filtration does not supply the
missing decrease.  Homogenization can retain (2) as a higher Rees face, but
it does not remove the degree-zero identity.  This does not forbid a Rees
standard basis after a genuinely new generator has been added; it proves
that the current return family alone is insufficient.

## Exact remaining theorem

The next cell must act nontrivially on the augmentation private quotient.  A
source-valid pointed occurrence/proper-face comparison must do at least one
of the following:

- kill the marked class;
- exchange it into a strictly smaller physical component; or
- move it into a named target/residue/anchor/`W` terminal summand.

Another coefficient extraction or factor localization cannot do this: the
factor `1-v04` is not a complete physical source equation, and the pinned
localization audit already separates that typing failure.  The appropriate
next attack is therefore the pointed higher cell, with every word/fine and
proper face retained, rather than a larger internal-support census.
