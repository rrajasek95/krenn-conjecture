# Normalizing `H0-u` does not make the cap comparison presentation-safe

## Outcome

The unique Eq obstruction is multiplied by the normalized source equation
`t=H0-u`, so it is tempting to set `t=0` and use the evident comparison from
the response carrier to the cap top.  This does make the coefficient map a
chain map.  It does not make it a quasi-isomorphism.

After base change, the reduced-Eq row is no longer hit.  The mapping cone has

```text
H0 = Q{e_Eq},   H1 = H2 = 0.
```

Thus its cone is not an acyclic, presentation-safe attachment.  A relative
cell with boundary `t e_Eq` does not fix the problem: after `t=0` it becomes
a new `H1` cycle while `e_Eq` remains in `H0`.  Only an absolute decorated
preimage of `e_Eq` removes both classes.  This is exactly the missing bright
response-to-cap comparison orbit.

## The two local complexes

Write the response packet as

```text
N -> Y
```

and the physical cap top as

```text
B -> Y + t E,                  t=H0-u.
```

At `t=0`, send `N` to `B` and `Y` to `Y`.  Both displayed nonzero
differentials are then the identity on `Y`, so this is a chain map.  But the
response complex is acyclic while the cap complex has the untouched class
`E`.  The explicit cone has dimensions

```text
C2 -> C1 -> C0 = 1 -> 2 -> 2
```

with

```text
d2(N)=(-B,Y),       d1(B)=Y,       d1(Y)=Y.
```

Its homology dimensions are `(H0,H1,H2)=(1,0,0)`, generated by `E`.

## Relative versus absolute repair

Adjoining `K_rel` with `dK_rel=tE` before base change is not an absolute
repair.  At `t=0` its differential vanishes, and the cap packet has

```text
(H0,H1)=(1,1),
```

generated by `E` and `K_rel`.  By contrast, an actual source-labelled cell
`K_abs` with `dK_abs=E` makes the local cap differential the identity matrix
and gives `(H0,H1)=(0,0)`.

This is the elementary Tor form of the protected `126 -> 127` obstruction.
It explains why coefficient normalization, evaluation at a normalized
source, and ordinary projective comparison over the common 90-parent module
cannot replace the enriched operation-changing cell.

## Scope
