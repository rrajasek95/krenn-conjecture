# The six-term dual survives the complete absolute source resolution

## Result

The homogeneous six-term repeated-component covectors are not artifacts of
truncating the source resolution at polynomial rows.  In each of the five
repeated `P3+K2` grades, the complete one-chart physical boundary map has

```text
288 columns, rank 288, kernel 0.
```

Consequently every absolute higher bar or source differential landing in
that labelled-column module is zero.  Indeed,

\[
 d_1d_2=0,\qquad \ker d_1=0
 \quad\Longrightarrow\quad d_2=0.                    \tag{1}
\]

No omitted absolute bar cell can therefore change the degree-one boundary
image or kill the six-term cokernel class.

For the doubled chart presentation the complete map is `[d1 d1]`, with

```text
576 columns, rank 288, kernel 288.
```

The kernel is exactly the anti-diagonal module generated by pairwise
`pq-pr` copies of the same labelled column.  The pure-row augmentation and
every chart-neutral physical readout have the same value on the two copies,
so they vanish on this whole kernel.  A chart-odd presentation cochain can
see it, but is not a descended physical terminal without the very higher
comparison being sought.

The natural C5 Tate map behaves identically at the next level.  Its `1440`
columns map to `1201` complete row/multiplier labels; the `239`-dimensional
kernel is the direct sum of coefficient-sum-zero spaces inside those label
fibres.  Pure aggregate, target, and anchor vanish on the whole kernel.

Finally, the pinned exact first-flat calculation proves that the canonical
six-term covector annihilates all `8580` complete order-six/Spencer operator
columns as well as the repeated polynomial columns.  The primitive pure
aggregate is not in their joint image.

## Structural conclusion

The following source types are exhausted:

1. every polynomial multiple of every complete full-nine row in the five
   repeated grades;
2. every absolute higher bar/source syzygy landing in those components;
3. both identical chart copies and their complete chart-difference kernels;
4. the natural degree-five Tate map and its whole kernel; and
5. the canonical complete first-flat order-six/principal-parts block.

Thus the first object that can kill the six-term class is necessarily a
**genuinely relative mapping-cone generator with a new physical output**.
It cannot be another absolute source syzygy, polynomial full-nine
correction, or chart-copy difference.  If that relative generator exists,
it is the missing physical comparison cell.  If it does not, the six-term
class survives as the physical cokernel candidate, subject only to terminal
typing.

\[
 \boxed{
   \text{one relative comparison cell}
   \quad\text{or}\quad
   \text{one homogeneous physical cokernel class}.
 }
\]

## Scope

The theorem is exhaustive for the absolute source/bar/Tate resolution in all
five complete repeated grades and for the canonical exact first-flat
principal-parts block.  It does not construct the relative mapping-cone
cell, prove cyclic physical propagation of the order-six block, identify the
six-term class with the final physical terminal, or prove transverse rank
landing.
